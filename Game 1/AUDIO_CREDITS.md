# Audio assets — 3D Combat Mode 1.1

All twelve Ogg/Opus files in `assets/combat-audio/` are original, locally generated synthesis, not sampled recordings. Their source waveforms were generated by `tools/generate_combat_audio.py` on 2026-10-12 and encoded as mono 48 kHz Opus with `tools/encode_combat_audio.sh`. Source, maker and license: Codex-generated original audio for this repository; no third-party recording, voice, music track, or external URL is embedded. The source scripts are included so the files can be reproduced (Python NumPy and FFmpeg required).

| File | In-game event |
|---|---|
| `district-ambience.ogg` | Ruined Clock District environmental loop |
| `combat-music.ogg` | Combat music loop |
| `stone-steps.ogg` | Movement and dash footsteps |
| `dash-whoosh.ogg` | Dodge and attack wind-up / miss |
| `punch-light.ogg` | Landed light combo and ORA strikes |
| `punch-heavy.ogg` | Heavy strike / guard break |
| `enemy-telegraph.ogg` | Enemy attack warning and time-wave warning |
| `enemy-hit.ogg` | Player damage and time-wave impact |
| `stand-summon.ogg` | Star Platinum activation and ORA sequence |
| `time-stop.ogg` | ZA WARUDO activation |
| `time-resume.ogg` | Time Stop release, anchor disable and mission finish |
| `chrono-echo.ogg` | Perfect dodge / Chrono Echo |

The 3D audio manager loads these local files only after the start click, offers master/music/ambience/effects levels and mute, and persists the settings in local storage. Audio timing, perceived quality and speaker output still need live-browser listening checks; this environment's local Playwright server cannot bind its port (`EPERM`). No Mixkit or MyInstants download was added. The repository's pre-existing Arcade MP3s are unchanged and retain their existing licensing status described in `THIRD_PARTY_NOTICES.md`.
