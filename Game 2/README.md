# Game 2 — RIFTBORN: ASCENSION

**Unity 6 / C# / URP — prototype v0.1**

Deze map is voor de tweede game, **RIFTBORN: ASCENSION**. De bestaande `Game 1` (Catcher-JoJo) blijft ongewijzigd.

## Wat is dit?

Een 3D third-person action RPG-prototype met beweging, dash, Lightning Spear, Gravity Wave, melee combat, meerdere vijanden, boss, XP/levels, HUD, basis Awakening Trial en een Rival-systeem.

## In Unity openen

1. Download de Unity-projectbestanden.
2. Pak het archief uit.
3. Open **Unity Hub → Add project from disk**.
4. Kies de map `Riftborn_Ascension_Unity`.
5. Gebruik Unity 6.x. Laat Unity de packages importeren.
6. Kies in Unity **RIFTBORN → 1 - Build or Rebuild Playable Scene**, open de gegenereerde scene en druk op Play.

**Let op:** Unity-projectbestanden zijn niet rechtstreeks speelbaar via GitHub Pages. Voor spelen in de browser is eerst een Unity WebGL-build nodig. De Unity-game is nog niet in de Unity Editor gecompileerd of getest.

## Besturing

WASD bewegen · Muis camera · Linkermuisknop combo · Rechtermuisknop heavy attack · Q Lightning Spear · E Gravity Wave · R ultimate · Shift dash · Spatie springen · Tab progressie · Esc pauze.
